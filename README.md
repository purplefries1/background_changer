# background_changer
A simple bash script that change your GNOME background every 30 seconds

## Overview
The script randomly selects a picture from a chosen folder and sets it as your desktop background.
The script only works on GNOME-like environments.

## Installation
1. Make the script executable:
```bash
chmod +x background_changer.sh"
```
2. run it:
```bash
./background_changer.sh
```
3. Choose your wallpaper directory

## Notes
Only JPG and PNG files are used.
